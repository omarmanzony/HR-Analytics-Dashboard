<h1 align="center">HR Analytics Dashboard</h1>

<p align="center">

</p>

<h2>Project Overview</h2>

HR Analytics Dashboard is an interactive business intelligence solution developed using Microsoft Power BI to analyze workforce structure, hiring activity, employee demographics, leave and absence patterns, and employee satisfaction.

The dashboard provides a structured analytical view of employee distribution, departments, job titles, hiring trends, hiring sources, sick leave, employee demographics, and satisfaction through interactive visualizations and filters.

<h2>Business Objectives</h2>

- Analyze overall workforce distribution.
- Evaluate employee distribution across departments and job titles.
- Analyze employee demographics and age distribution.
- Track hiring activity and hiring trends over time.
- Identify the main sources used for employee recruitment.
- Analyze hiring activity across departments.
- Monitor leave and sick leave patterns.
- Analyze employee satisfaction levels.
- Identify workforce patterns and organizational trends.
- Provide an interactive dashboard for HR performance analysis.
- Support data-driven HR decision-making.

<h2>Key Performance Indicators</h2>

The dashboard provides a set of core HR performance metrics including:

- Total Employees
- Total Departments
- Total Job Titles
- Hiring Sources
- Hiring Count
- Average Age
- Sick Leave
- Employee Satisfaction

These KPIs provide a high-level overview of workforce structure, recruitment activity, employee demographics, leave patterns, and satisfaction.
